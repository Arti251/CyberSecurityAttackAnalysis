# 🛡️ Cyber Security Attack Analysis

## 📌 Project Overview

This project analyzes cybersecurity attack data to identify attack patterns, network vulnerabilities, protocol usage, and security risks. The analysis follows an end-to-end data analytics workflow, including data preprocessing, exploratory data analysis (EDA), SQL querying, and interactive dashboard development.

The objective is to transform raw cybersecurity logs into actionable business insights that support threat monitoring and decision-making.

---

## 🎯 Project Objectives

- Clean and preprocess cybersecurity attack data.
- Perform exploratory data analysis (EDA).
- Analyze attack patterns using SQL.
- Build interactive Tableau dashboards.
- Generate business insights and recommendations.

## 🔍 Key Findings

- The dataset contains **40,000 cybersecurity attack records**.
- Attack types are evenly distributed across categories.
- High, Medium, and Low severity attacks occur in similar proportions.
- Network segments experience balanced attack volumes.
- TCP, UDP, and ICMP protocols are commonly used across attacks.
- Numerical features exhibit very weak correlations.
- Attack activity remains relatively stable over time.

---

## 💡 Business Recommendations

- Continuously monitor all network segments.
- Prioritize investigation of high-severity incidents.
- Implement automated monitoring for high anomaly scores.
- Strengthen protocol-specific security policies.
- Integrate predictive analytics for future threat detection.
