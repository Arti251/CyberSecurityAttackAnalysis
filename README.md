# Cyber Security Attack Analysis

## Objective
Analyze cyber attack patterns and identify vulnerable systems using Python and MySQL.

## Features
- Attack frequency analysis
- Threat severity analysis
- IP-based threat monitoring
- Anomaly detection
- Interactive dashboards

## Tech Stack
- Python
- MySQL
- Pandas
- Scikit-learn
- Streamlit
